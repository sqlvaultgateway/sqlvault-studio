SQLVault Studio 0.2.0

Client SQL gratuit et complet, sans aucune limite, pour apprendre et développer.

Nouveautés
- Installation simple : assistant Suivant / Suivant sur Windows, application à glisser dans Applications sur macOS.
- Serveur MySQL ou PostgreSQL en un clic, comme XAMPP (téléchargé une seule fois, arrêté à la fermeture).
- Créer une table avec un formulaire, clés étrangères comprises ; le SQL généré s'affiche.
- Importer et exporter des fichiers .sql (base entière ou tables choisies), créer et supprimer des bases.
- Modifier une cellule par double-clic, insérer et supprimer des lignes ; la requête envoyée s'affiche.
- Trier et filtrer chaque colonne du résultat, comme dans Excel.
- Exporter le résultat complet d'une requête en Excel, CSV, JSON ou INSERT.

Fichiers
- Windows 10 / 11 : SQLVault-Studio-0.2.0-Windows-x64.exe
- macOS 13+ (puce Apple ou Intel) : SQLVault-Studio-0.2.0-macOS.dmg
- Linux : sqlvault-studio-0.2.0-linux-amd64.zip ou -linux-arm64.zip
- Docker : docker run -d -p 127.0.0.1:4320:4320 -v sqlvault-studio:/data mbodji/sqlvault-studio
- Guide utilisateur : SQLVault-Studio-Guide-utilisateur.pdf (19 pages illustrées)

Installation en ligne de commande
- macOS, Linux : curl -fsSL https://raw.githubusercontent.com/sqlvaultgateway/sqlvault-studio/main/install.sh | sh
- Windows : irm https://raw.githubusercontent.com/sqlvaultgateway/sqlvault-studio/main/install.ps1 | iex
- Empreintes de contrôle : SHA256SUMS.txt

Premier lancement : l'application n'est pas encore signée.
- Windows : « Informations complémentaires » puis « Exécuter quand même ».
- macOS : Réglages Système › Confidentialité et sécurité › « Ouvrir quand même ».
